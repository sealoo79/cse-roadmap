# course_fields.json

## 이 데이터가 의미하는 것

**과목별 분야**입니다. `primary_field_id`는 노선도에서 그 과목이 놓이는 행(노선) 하나, `field_ids`는 추천에서 관심 분야와 비교하는 분야 목록(대표 분야 포함)입니다.

`curriculum.json`에 나오는 과목 122개 전부를 담았습니다(교양 3과목 포함). 노선도 레이아웃(#7)이 빈 행 없이 모든 과목을 배치할 수 있게 하기 위해서입니다.

```
course_fields.json ──(course_code)── courses.json
                   └─(primary_field_id, field_ids)── fields.json
```

## 서비스에서 쓰이는 기능

| 기능 | 사용하는 필드 | 쓰임 |
|---|---|---|
| 노선도 행 배치 (#7) | `primary_field_id` | `layoutRoadmap()`이 과목을 이 행에 놓음 |
| 노선 색 (#7, #20) | `primary_field_id` | 역(과목) 색 = 분야 색 |
| 관심 분야 추천 (#13) | `field_ids` | 관심 분야와 하나라도 겹치면 가산 |
| 분야 필터 (#20) | `primary_field_id` | 선택한 분야의 행만 표시 |

## 필드

| 필드 | 타입 | 설명 |
|---|---|---|
| `course_code` | string | `courses.json`의 과목코드 |
| `primary_field_id` | string | 노선도 행(대표 분야) |
| `field_ids` | string[] | 대표 분야를 맨 앞에 두고 보조 분야를 이어 붙인 목록 |
| `basis` | string | `official`(학부 공식 분류) · `team_proposal`(팀 제안). 학부 공식 분야 분류가 없어 **전부 `team_proposal`** |
| `name_ko` | string | 검토용 과목명. **옵셔널 추가 필드**(과목명은 표시·검토용, 식별은 코드로만) |
| `note` | string \| null | 근거 메모. 프로토타입 노선도에 있던 과목은 `"프로토타입 노선도 배치"` **옵셔널 추가 필드** |

## 분류 기준

- **공통 기초**: 프로그래밍·수학 기초, 이산수학, 자료구조, 알고리즘, 문제해결, 설계·종합설계·공학연수, 특강, 그리고 교양·기본소양·창업·교직 과목. 특정 분야로 묶기 어려운 과목은 노선도가 비지 않도록 여기 둡니다.
- **AI·데이터**: 인공지능·기계학습·딥러닝·비전·자연어·음성, 확률통계·선형대수·수치해석, 데이터과학·데이터마이닝·정보검색, 생물정보학·의료AI·HCI.
- **시스템**: 논리회로·디지털설계, 컴퓨터구조, 운영체제, 시스템프로그래밍, 컴파일러·프로그래밍언어론·오토마타, 병렬·클라우드·양자 컴퓨팅, 임베디드.
- **네트워크·보안**: 데이터통신, 컴퓨터망, 네트워크 프로그래밍, 모바일 네트워크·모바일 컴퓨팅·사물인터넷, 정보보호·정보보안·웹보안.
- **소프트웨어·웹**: 자바·객체지향 응용, 소프트웨어 설계·공학·테스팅, 데이터베이스, 웹·모바일 앱, 오픈소스, 그래픽스·게임·AR·미디어아트.
- 프로토타입 노선도에 배치된 38과목은 그 행을 그대로 따랐고, 나머지 84과목은 위 기준으로 만든 초안입니다.
