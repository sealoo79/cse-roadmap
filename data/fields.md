# fields.json

## 이 데이터가 의미하는 것

**노선도의 분야(노선) 5개**입니다. 노선도의 행, 노선 색, 범례, 관심 분야 선택 카드, 졸업요건 화면의 분야별 막대가 이 파일을 씁니다.

```
fields.json ──(field_id)── course_fields.json (primary_field_id, field_ids)
            └─(field_id)── user_interests.field_id (Supabase, 사용자 관심 분야)
```

## 서비스에서 쓰이는 기능

| 기능 | 사용하는 필드 | 쓰임 |
|---|---|---|
| 노선도 행·범례 (#7) | `field_id`, `name_ko`, `color`, `order` | 위에서부터 `order` 순서로 행을 그리고 노선 색을 칠함 |
| 관심 분야 선택 (#10) | `name_ko`, `description`, `color` | 온보딩 3단계 카드 |
| 추천 (#13) | `field_id` | 관심 분야와 과목의 `field_ids`가 겹치면 가산 |

## 필드

| 필드 | 타입 | 설명 |
|---|---|---|
| `field_id` | string | 고정 키(AGENTS.md A-3). 바꾸지 않음 |
| `name_ko` | string | 화면 표시 이름 |
| `color` | string | 라이트 테마 노선 색(`#rrggbb`) |
| `order` | number | 노선도 행·범례 순서(1이 맨 위) |
| `color_dark` | string | 다크 테마 노선 색. **옵셔널 추가 필드** |
| `description` | string | 관심 분야 카드 설명. **옵셔널 추가 필드** |

## 알아둘 점

- 색과 행 순서는 프로토타입(`cse-roadmap_8.html`) 노선도를 그대로 따랐습니다. 라이트 색은 서울 지하철 1·2·3·5호선 색입니다.
- 화면 색은 AGENTS.md 규칙대로 CSS 변수와 이 파일의 색만 씁니다. `prefers-color-scheme: dark`이면 `color_dark`를 씁니다.
- 이름·색은 팀이 PR에서 확정합니다.
