# curriculum.json

## 이 데이터가 의미하는 것

**"어느 입학년도의 어느 전공 학생이, 몇 학년 몇 학기에, 어떤 과목을 듣도록 교육과정표에 배치돼 있는가"** 를 한 줄씩 기록한 파일입니다. 교육과정표의 칸 하나가 객체 하나이며 총 598행입니다.

로드맵 화면(학년·학기별 과목 배치)과 졸업요건 계산(전공필수 과목 목록)의 기준 데이터입니다.
과목의 이름이나 학점 같은 기본 정보는 이 파일에 없고, `course_code`로 `courses.json`에서 조회합니다.

```
curriculum.json ──(course_code)── courses.json
                └─(program_id)── programs.json
                └─ (admission_year + program_id) ── graduation_rules.json
```

## 서비스에서 쓰이는 기능

| 기능 | 사용하는 필드 | 쓰임 |
|---|---|---|
| 온보딩: 이수 과목 체크 (①) | `grade`, `semester`, `course_code` | 학생의 입학년도·전공에 해당하는 과목을 학년별로 나열해 이수 여부를 체크하게 함 |
| 로드맵 생성: 학기 격자 (②) | `grade`, `semester`, `course_code`, `category` | 1~4학년 × 1·2학기 칸에 과목을 배치하고, 이수 완료·추천·수강 가능 상태를 구분해 표시 |
| 로드맵 생성: 선수 트리 (④) | `grade`, `course_code` | 학년 열별로 과목 카드를 배치. 화살표는 `course_relations.json`으로 그림 |
| 수강 과목 추천 | `is_required`, `grade`, `semester` | 아직 이수하지 않은 전공필수와 현재 학기에 맞는 과목을 우선 추천 |
| 졸업요건: 남은 전공필수 (③) | `is_required`, `course_code` | 전공필수 과목 중 이수하지 않은 과목을 표시 |
| 졸업요건: 영역별 이수 현황 (③) | `category`, `course_code` | 이수한 과목을 `category`(전공, 교양, 공학전공 등)로 묶어 학점 합산 |
| 카테고리 필터 | `tags`, `category` | 창업, 설계, 교양 영역 같은 표기로 과목을 걸러 보기 |

학생의 `admission_year`와 `program_id`로 **먼저 필터해야** 위 기능이 모두 맞게 동작합니다. 과목 이름과 학점은 `courses.json`, 졸업 기준 학점은 `graduation_rules.json`에서 가져옵니다.

## 필드

| 필드 | 타입 | 설명 | 예시 |
|---|---|---|---|
| `admission_year` | number | 입학년도 (교육과정이 적용되는 학번 기준) | `2025` |
| `program_id` | string | 전공 (`programs.json`의 `program_id`) | `"platform_sw_data"` |
| `course_code` | string | 과목코드 (`courses.json` 참조) | `"COME0331"` |
| `grade` | number | 학년 (1~4) | `2` |
| `semester` | number | 학기 (1 또는 2) | `1` |
| `category` | string | 교과 구분. 원문 교육과정표의 구분 그대로이며 전공마다 값이 다름 (아래 표). **화면 표시용** | `"공학전공"` |
| `credit_bucket` | string | 학점 계산용 표준 키. `category`를 아래 표대로 바꾼 값이며 `graduation_rules.json`의 `credit_buckets[].bucket_id`와 같은 키를 씀. **#2에서 추가** | `"engineering_major"` |
| `is_required` | boolean | 전공필수(필수) 과목 여부. 해당 연도·전공의 교육과정표에 필수로 표시된 과목 | `true` |
| `tags` | string[] | 원문 비고에 있던 그 밖의 표기. 없으면 빈 배열 (아래 표) | `["설계"]` |

한 행의 기본 키는 `admission_year` + `program_id` + `course_code`입니다.

### `category` → `credit_bucket`

| `category` | `credit_bucket` |
|---|---|
| `전공` | `major` |
| `공학전공` | `engineering_major` |
| `전공기반` | `major_base` |
| `기본소양` | `basic_literacy` |
| `교양` | `liberal` |
| `일반선택` | `general_elective` |
| `교직` | `teaching` |

졸업요건 계산은 `category` 대신 `credit_bucket`으로 묶습니다. 전공마다 다른 원문 표기를 코드에서 분기하지 않기 위해서입니다.

### `category` 값

| 값 | 쓰이는 전공 |
|---|---|
| `전공` | 글로벌SW융합, 인공지능컴퓨팅, 심화컴퓨팅, 첨단컴퓨팅연구 |
| `교양`, `일반선택` | 글로벌SW융합, 인공지능컴퓨팅 (교양은 심화컴퓨팅, 첨단컴퓨팅연구에도 있음) |
| `교직` | 심화컴퓨팅, 플랫폼SW&데이터과학 |
| `기본소양`, `전공기반`, `공학전공` | 플랫폼SW&데이터과학 (ABEEK 교과구분) |

> 전공마다 구분 이름 체계가 다릅니다. ABEEK 교육과정(플랫폼SW&데이터과학)은 `기본소양 / 전공기반 / 공학전공`이고, 나머지는 `전공 / 교양 / 일반선택 / 교직`입니다.
> 학점 요건을 영역별로 합산할 때는 `category`로 묶되, 전공마다 값이 다르다는 점을 감안해야 합니다.

### `tags` 값

| 값 | 의미 | 건수 |
|---|---|---|
| `창업` | 창업 교과목 표시 (글솝) | 27 |
| `설계` | 설계 과목 표시 (플랫폼SW&데이터과학, ABEEK 설계학점 14학점과 관련) | 21 |
| `KNU미래설계` | 2023학번부터 적용되는 KNU미래설계 교과목 | 15 |
| `첨성인핵심(인문사회)` / `첨성인핵심(예술과 표현)` / `첨성인핵심(자연과학)` | 교양 영역 표시 | 6 / 3 / 3 |
| `첨성인기초(글쓰기)` / `첨성인기초(수리)` / `첨성인기초(SW)` | 교양 영역 표시 | 3 / 3 / 3 |
| `인문교양` | 인문교양 표시 (2023·2024 글솝) | 6 |
| `SDG` | SDG 교양 표시 (2025 글솝) | 2 |

## 예시

```json
{
  "admission_year": 2026,
  "program_id": "adv_computing",
  "course_code": "COMP0206",
  "grade": 1,
  "semester": 1,
  "category": "전공",
  "credit_bucket": "major",
  "is_required": true,
  "tags": []
}
```

읽는 법: 2026학번 심화컴퓨팅전공 학생은 1학년 1학기에 기초프로그래밍(`COMP0206`)을 듣고, 이 과목은 전공필수입니다.

## 연도·전공별 행 수

| 입학년도 | 전공 | 행 수 |
|---|---|---|
| 2023 / 2024 / 2025 | 글로벌SW융합 | 각 60 |
| 2023 / 2024 / 2025 | 플랫폼SW&데이터과학 | 각 78 |
| 2026 | 심화컴퓨팅 | 67 |
| 2026 | 인공지능컴퓨팅 | 60 |
| 2026 | 첨단컴퓨팅연구 | 57 |

## 서비스에서 조회하는 방법

학생의 입학년도와 전공으로 반드시 필터합니다.

```
admission_year == 학생의 입학년도
program_id == 학생의 전공
```

- 로드맵: 필터된 행을 `grade`, `semester`로 묶어 학년·학기 칸에 배치
- 졸업요건의 남은 전공필수: 필터된 행 중 `is_required == true`인 과목에서 학생이 이수한 과목을 뺌

## 알아둘 점

- **같은 과목도 전공·연도마다 학년, 학기, 필수 여부가 다릅니다.** 과목 하나만 보고 "필수"라고 표시하면 틀리므로 항상 입학년도와 전공으로 필터해야 합니다. 필수 여부가 전공에 따라 다른 과목이 12개 있습니다.
- 인공지능컴퓨팅은 2026만 있고 2023~2025가 없습니다(`programs.json`의 `years`에서 `curriculum_status: "missing"`).
- 학년·학기 배치는 PDF와 이미지 표의 레이아웃에서 읽은 것이라 일부 틀릴 수 있습니다. 교육과정표의 과목 수는 원문의 과목코드 수와 맞는지 확인했습니다.
- 과목이 실제로 어느 학기에 개설되는지는 이 파일이 아니라 개설 데이터(분반 데이터)를 확인해야 합니다. 교육과정표의 배치는 권장 학기입니다.
- `is_required`는 교육과정표 표기 기준입니다. 졸업요건 문서가 따로 있는 전공(2026)은 `graduation_rules.json`의 필수 과목 목록과 일치하는 것을 확인했습니다.
