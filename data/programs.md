# programs.json

## 이 데이터가 의미하는 것

**컴퓨터학부의 전공(프로그램) 목록**과, 각 전공이 어느 입학년도에 존재하는지, 그리고 그 중 교육과정 자료가 확보된 연도와 아직 없는 연도를 담은 파일입니다. 전공 하나가 객체 하나이며 총 5개입니다.

서비스에서 학생이 입학년도를 선택하면 그 연도에 있는 전공 3개를 보여주고, 교육과정 자료가 없는 전공은 "준비 중"으로 안내하는 데 사용합니다.
다른 파일에서 쓰는 `program_id`의 기준 목록이기도 합니다.

```
programs.json ──(program_id)── curriculum.json
              ├─(program_id)── graduation_rules.json
              └─(program_id)── course_relations.json
```

## 서비스에서 쓰이는 기능

| 기능 | 사용하는 필드 | 쓰임 |
|---|---|---|
| 온보딩: 입학년도·전공 선택 (①) | `program_id`, `name`, `offered_years` | 학생이 입학년도를 고르면 그 연도에 있는 전공만 보여줌 |
| 자료 없음 안내 | `missing_curriculum_years`, `note` | 선택한 연도·전공의 교육과정 자료가 없으면 로드맵 대신 "교육과정 자료 준비 중" 안내 |
| 모든 화면의 전공 이름 표시 | `name` | 로드맵·졸업요건 화면 상단의 "23학번 · ○○전공" 같은 표시 |
| 다른 JSON 조회의 기준 | `program_id` | `curriculum`, `graduation_rules`, `course_relations`를 `program_id`로 필터할 때의 기준 값 |

핵심 기능(로드맵 생성, 졸업요건 달성 여부)은 이 파일의 `program_id`를 키로 다른 파일을 조회하므로, **전공 선택 단계가 이 파일에서 시작**합니다.

## 필드

| 필드 | 타입 | 설명 | 예시 |
|---|---|---|---|
| `program_id` | string | 전공 식별자. 이 파일의 기본 키이며 다른 파일이 이 값으로 전공을 참조함 | `"ai_computing"` |
| `name` | string | 전공 이름 | `"인공지능컴퓨팅전공"` |
| `college` | string | 소속 | `"컴퓨터학부"` |
| `offered_years` | number[] | 이 전공이 존재하는 입학년도 | `[2023, 2024, 2025, 2026]` |
| `curriculum_years` | number[] | 그 중 교육과정 자료(`curriculum.json`)가 있는 입학년도 | `[2026]` |
| `missing_curriculum_years` | number[] | 전공은 있지만 교육과정 자료가 없는 입학년도 | `[2023, 2024, 2025]` |
| `note` | string \| null | 보충 설명 | `"2023~2025 교육과정 자료 없음(2026만 있음)"` |

## 전공 목록

| `program_id` | 전공 | 존재하는 입학년도 | 교육과정 자료 |
|---|---|---|---|
| `platform_sw_data` | 플랫폼SW&데이터과학전공 | 2023~2025 | 2023~2025 |
| `global_sw` | 글로벌SW융합전공 | 2023~2025 | 2023~2025 |
| `ai_computing` | 인공지능컴퓨팅전공 | 2023~2026 | 2026만 |
| `adv_computing` | 심화컴퓨팅전공 | 2026 | 2026 |
| `adv_research` | 첨단컴퓨팅연구전공 | 2026 | 2026 |

입학년도별로 보여줄 전공은 다음과 같습니다.
- 2023~2025학번: 플랫폼SW&데이터과학, 글로벌SW융합, 인공지능컴퓨팅
- 2026학번: 심화컴퓨팅, 첨단컴퓨팅연구, 인공지능컴퓨팅

## 예시

```json
{
  "program_id": "ai_computing",
  "name": "인공지능컴퓨팅전공",
  "college": "컴퓨터학부",
  "offered_years": [2023, 2024, 2025, 2026],
  "curriculum_years": [2026],
  "missing_curriculum_years": [2023, 2024, 2025],
  "note": "2023~2025 교육과정 자료 없음(2026만 있음)"
}
```

## 알아둘 점

- 학생이 "2024학번"을 고르면 `offered_years`에 2024가 있는 전공만 보여주면 됩니다.
- 선택한 연도가 `missing_curriculum_years`에 있으면 로드맵을 만들 수 없으므로 "교육과정 자료 준비 중"으로 안내해야 합니다. 지금은 인공지능컴퓨팅 2023~2025가 그렇습니다.
- `platform_sw_data`의 교육과정은 심화컴퓨터공학프로그램(ABEEK) 교육과정표(2023~2025)를 사용했습니다. 이 연결은 사용자가 확인해 준 내용이며, `note`에도 적혀 있습니다.
- 전공이 늘거나 이름이 바뀌면 이 파일에 한 줄을 추가하면 됩니다. 이름이 바뀌어도 `program_id`는 유지해야 다른 파일의 연결이 끊어지지 않습니다.
- 이 파일은 5줄뿐이라 코드에 직접 써넣어도 동작하지만, 파일로 두면 연도·전공이 늘 때 데이터만 수정하면 됩니다.
