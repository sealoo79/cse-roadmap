# requirement_courses.json — 졸업요건 항목별 인정 과목 (1:N)

졸업요건 항목 1개에 인정 과목 N개를 묶은 테이블입니다. `courses`는 `courses.json`의 `course_code`를 참조합니다.
학점 기준만 있는 요건은 `graduation_rules.json`, **어떤 과목이 그 요건으로 인정되는지**는 이 파일이 담당합니다.

## 필드

| 필드 | 설명 |
|---|---|
| `requirement_id` | 고정 키. 전공별 항목은 `종류__전공__학번` 형식 |
| `name`, `group` | 항목명, 묶음(교양 영역별 필수·졸업자격인정제·전공·전공필수·공학인증(ABEEK)·창업·설계·현장실습·참고) |
| `program_ids` | 적용 전공 배열. `null`이면 5개 전공 공통 |
| `admission_years` | 적용 입학년도 |
| `min_credits` / `min_credits_detail` | 최소 이수학점(없으면 null) / 조건별 학점 |
| `rule` | 충족 규칙 원문 요약 |
| `counts_for_graduation` | false면 참고용 목록(졸업 계산에 쓰지 않음) |
| `checklist_key` | 졸업자격인정제 등 비학점 요건과 연결되면 그 키(`gq_practical_english` 등), 아니면 null |
| `input_required` | true면 과목 이수만으로 판정할 수 없어 학생 입력이 필요(어학성적 대체, 대상 과목 미정 등) |
| `course_count`, `courses` | 인정 과목 수, 인정 과목 코드 목록 |
| `course_basis`, `source`, `note` | 목록을 뽑은 기준, 규정 출처, 예외·한계 |
